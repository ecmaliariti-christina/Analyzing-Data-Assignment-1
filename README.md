# NLP Analysis of Literary Texts

This repository contains Jupyter Notebook code for performing Natural Language Processing (NLP) analysis on literary texts using NLTK and spaCy.

## Part I – Tokenization & Stemming

Sentence splitting and word tokenization (NLTK & spaCy)

Word frequency statistics (per text and combined corpus)

Visualization of the 25 most frequent words

Stemming using Porter and Lancaster stemmers

Comparison between stemmed and unstemmed results

## POS Tagging 

POS tagging using spaCy models for:

English (en_core_web_sm)

Dutch (nl_core_news_sm)

German (de_core_news_sm)

Frequency comparison of POS tags across languages

Interpretation of structural differences reflected in tag distributions

## Part II – Named Entity Recognition (NER)

Automatic entity detection using spaCy

Manual annotation of selected sentences

Evaluation of model performance

Discussion of limitations in domain-specific (fictional) texts

## Tools Used:

Python

NLTK

spaCy
